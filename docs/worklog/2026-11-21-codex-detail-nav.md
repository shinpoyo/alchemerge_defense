# 2026-11-21 図鑑の詳細を前後に送れるようにする

## 依頼
図鑑のページを「次」「前」などで、毎回閉じなくても次の項目に移れるようにしてほしい。

## やったこと
- 図鑑のカードから開いた詳細画面の下に「‹ 前へ」「とじる」「次へ ›」を並べた。
- 送る順番は図鑑の並び（★1→★6、図鑑と同じ順）で、見つけた元素だけ。端では押せない表示になる。
- スマホでは詳細を左右にはらっても前後に移れる（左へはらうと次）。PCでは ← → キーでも送れる。
- 盤面や一覧の長押しで開いた詳細には、前後ボタンを出さない（図鑑から開いたときだけ）。
- 詳細の中でレシピの元素をタップして移ったあとも、その元素を基準に前後へ送れる。
- 続けて押せるよう、前後に送るときは「開いた直後のクリックを捨てる」仕組みを使わない。

## 確認
- Playwright（iPhone SE 相当）で、図鑑→火→次へ→水→次へ→土→前へ→水、左はらいで土、とじるで図鑑に戻ることを確認。エラーなし。
