# 月の恵み（2026-11-25）

## やったこと
- 波を退けたあと、札を 3 枚見せて 1 枚えらぶ「月の恵み」を追加（`js/moon.js` を新しく作り、`battle.js` の後に読みこむ）
- 出るのは最後の波より前の 5 波ごと（20 波なら第 5・10・15 波のあと）。エンドレスでも 5 波ごと
  - ステージごとの波数（10・15・20 波）が入ったら `maxWave()` に合わせる（`lastWave()` で、あれば使う）
- 効果はその戦いのあいだだけ。途中保存にも残る（えらぶ前に閉じても、再開すると同じ 3 枚がまた出る）
- 一時停止の画面に、えらんだ札の一覧を出す
- 同じ札は 2 回出ない。加護だけは系統がちがえば出る（盤面にある元素の系統からえらぶ）

## 札（11 枚。ユーザーと決めた内容）
| 札 | 効果 | 代償 |
|---|---|---|
| 〇〇の加護 | その系統の威力 +25% | ほかの系統 −5% |
| 深い罠 | 罠の効き目と広さ +20% | 塔の威力 −5% |
| 満ちる月 | 波の終わりの魔力 1.5 倍 | 影の足 +5% |
| 赤い月 | すべての威力 +30% | 灯 −3（1 は残る） |
| 欠けた月 | 工房の値段 ×0.75 | 影の足 +10% |
| 灯籠の明かり | 支援の塔が強める量 1.5 倍 | なし |
| 錬成の余り | 錬成ごとに魔力 +2 | なし |
| 灯をともす | 灯 +3 | なし |
| 長い夜 | 状態異常の続く時間 1.5 倍 | なし |
| 影の落とし物 | 倒したときの魔力 +20% | なし |
| 鎧くだき | 鎧の影の守り 1/4 → 1/2 | なし |

検討の途中で外したもの：安い呼び出し（ユーザー判断で不要）、欠けた月の半額（強すぎる）。
