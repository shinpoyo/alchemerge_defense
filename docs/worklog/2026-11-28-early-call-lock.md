# 2026-11-28 早呼びに「呼び出せない」代償を付ける

## きっかけ
早呼びは「波終了の魔力の先払い＋ボーナス」で、敵が重なる以外の代償がなく得なだけだった（ユーザー指摘）。案B「早呼び中は購入できない」に決定。

## 仕様
- 早呼びを押した時点で場に残っていた敵（前の波の敵）に印を付ける。分かれる影から出た小さい影も印を引き継ぐ。
- 印の付いた敵が全部いなくなる（倒す・灯に届く）まで、下の一覧から呼び出せない（元素も工房レベルも）。
- 合成・配置・移動・還す・最高ランク強化・戻すは止めない。
- 図鑑・詳細の「購入」ボタンも押せない札（🔒 早呼び中は呼べない）にする。
- 魔力の先払い・早呼びボーナスはそのまま。

## 画面
- 早呼びチップの左に「代償：前の波の敵がいなくなるまで呼び出し不可」と出し、押す前に分かるようにした。
- 呼び出せない間は一覧を暗くし、帯で「🔒 早呼び中：前の波の敵があと N 体いなくなるまで呼び出せない」と残り数を出す。
- 文言は lang.js に日英（earlyLock / earlyCost / earlyLockShort）。ヘルプには早呼びの説明がないので変更なし。

## 確認
- Playwright で宵の回廊：第1波を出し切って早呼び → spawnBase が 'lock' を返す、印の敵を消すと解除され呼び出せることを確認。コンソールエラーなし。
