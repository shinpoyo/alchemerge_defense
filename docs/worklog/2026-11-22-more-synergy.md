# 2026-11-22 系統特効（属性シナジー）を増やす

## 依頼
「系統特効、特定系統に効きやすくする効果を増やして」

## 変更
これまでは「水→濡れ→雷×1.5」「氷→脆化→土×1.5」の2つだけだった。表 SYN にまとめ、4つ足した。

| かける系統 | 状態 | よく効く系統 | ねらい |
|---|---|---|---|
| 水 | 濡れ | 雷 | （既存） |
| 氷 | 脆化 | 土 | （既存） |
| 風 | 冷え | 氷 | 風に吹かれて冷えた影は凍りやすい。風の出番を増やす |
| 毒 | 蝕み | 風 | 毒に蝕まれた体は風に裂かれやすい |
| 闇 | 怯え | 光 | 闇に怯えた影は光に焼かれる |
| 光 | 眩み | 闇 | 光に目が眩んだ影は闇に呑まれる |

- 倍率 ×1.5、持続 2.5 秒（ボスは半分）は既存と同じ。複数の状態が重なっても倍率は1回だけ。
- 2系統の元素（MULTI）に「かける側とよく効く側」の両方を持つものがないことを確認（自分で自分を強めない）。
- 詳細画面：かける側は「敵にかける効果」に、よく効く側は説明の下に「「蝕み」の敵に ×1.5（毒の攻撃でかかる）」と出る。
- 影の見た目：冷え・蝕み・怯え・眩みは、その色の回る短い輪と、頭上右の丸印。

## 確かめたこと
- コンソールエラーなし。状態のある影に風で当てると 10→15（×1.5）、炎は 10 のまま。
- 自動プレイ（simBases.js、ステージ0・5・12、全基本元素／水＋風）：変更前とほぼ同じ結果。
- スクリーンショット：/mnt/project-files/element-syn/

## 追記（2026-11-23）：状態をかける元素をしぼる
ユーザー指摘「水系統が全部濡れを起こしているならダメ」。これまでは系統の全部がかけていたので、名前や効果に合う元素だけにした（SYN[].by）。

| 状態 | かける元素 |
|---|---|
| 濡れ | 海・雨雲・間欠泉・津波・嵐・台風・海神（水15種→7種） |
| 脆化 | 吹雪・氷床・氷河期・絶対零度（氷12種→4種） |
| 冷え | 旋風・竜巻・嵐・台風・風神 |
| 蝕み | 瘴気・腐蝕・疫病・冥府 |
| 怯え | 墓・闇夜・怨霊・死神・百鬼夜行 |
| 眩み | 閃光・虹・聖光・太陽 |

- 基本の水・氷はかけない（序盤から簡単にかかりすぎるため）。よく効く側は今まで通り系統の全部。
- 詳細画面の「敵にかける効果」も、かける元素だけに出る（水には出ず、海には出る）。
- main（時・夢の追加 PR #37）を取りこみ、状態名の行のコンフリクトを解消。
- 自動プレイ（ステージ0・5・8、全基本元素）：main とほぼ同じ結果。
