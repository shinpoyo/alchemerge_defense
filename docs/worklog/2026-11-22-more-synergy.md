# 2026-11-22 系統特効（属性シナジー）を増やす

## 依頼
「系統特効、特定系統に効きやすくする効果を増やして」

## 変更
これまでは「水→濡れ→雷×1.5」「氷→脆化→土×1.5」の2つだけだった。表 SYN にまとめ、4つ足した。

| かける系統 | 状態 | よく効く系統 | ねらい |
|---|---|---|---|
| 水 | 濡れ | 雷 | （既存） |
| 氷 | 脆化 | 土 | （既存） |
| 風 | 冷え | 氷 | 風に吹かれて冷えた影は凍りやすい。風の出番を増やす |
| 毒 | 蝕み | 風 | 毒に蝕まれた体は風に裂かれやすい |
| 闇 | 怯え | 光 | 闇に怯えた影は光に焼かれる |
| 光 | 眩み | 闇 | 光に目が眩んだ影は闇に呑まれる |

- 倍率 ×1.5、持続 2.5 秒（ボスは半分）は既存と同じ。複数の状態が重なっても倍率は1回だけ。
- 2系統の元素（MULTI）に「かける側とよく効く側」の両方を持つものがないことを確認（自分で自分を強めない）。
- 詳細画面：かける側は「敵にかける効果」に、よく効く側は説明の下に「「蝕み」の敵に ×1.5（毒の攻撃でかかる）」と出る。
- 影の見た目：冷え・蝕み・怯え・眩みは、その色の回る短い輪と、頭上右の丸印。

## 追記（2026-11-23）：状態をかける元素をしぼる
ユーザー指摘「水系統が全部濡れを起こしているならダメ」。これまでは系統の全部がかけていたので、名前や効果に合う元素だけにした（SYN[].by）。

| 状態 | かける元素 |
|---|---|
| 濡れ | 海・雨雲・間欠泉・津波・嵐・台風・海神（水15種→7種） |
| 脆化 | 吹雪・氷床・氷河期・絶対零度（氷12種→4種） |
| 冷え | 旋風・竜巻・嵐・台風・風神 |
| 蝕み | 瘴気・腐蝕・疫病・冥府 |
| 怯え | 墓・闇夜・怨霊・死神・百鬼夜行 |
| 眩み | 閃光・虹・聖光・太陽 |

- 基本の水・氷はかけない（序盤から簡単にかかりすぎるため）。よく効く側は今まで通り系統の全部。
- 詳細画面の「敵にかける効果」も、かける元素だけに出る（水には出ず、海には出る）。
- main（時・夢の追加 PR #37）を取りこみ、状態名の行のコンフリクトを解消。
- 自動プレイ（ステージ0・5・8、全基本元素）：main とほぼ同じ結果。

## 追記（2026-11-23）：系統にこだわらない／冷え→乾き
ユーザー「系統にこだわらないことになったので、氷系統じゃないけど脆化する元素があってもいい」「冷えって変だぜ」。

- 脆化をかける元素に、系統の外から 錆・風化・石化（時）を足した（ものを朽ちさせる・石にする元素）。
- 冷え（風→氷）をやめ、**乾き**（旋風・竜巻・砂嵐・風神 → 炎 ×1.5）にした。風で乾いた影はよく燃える。雨を伴う嵐・台風は外した。
- SYN[].by は系統に縛らない。ただし、よく効く系統を持つ元素は入れない（自分で自分を強めない。スクリプトで確認）。
- よく効く側の一文は「「乾き」の敵に ×1.5（旋風・竜巻などがかける）」と、かける元素の名前を出す形に変えた。

## 追記（2026-11-23）：脆化 → ひび割れ
説明の「もろくする」（中身は呪い：全部の攻撃で受ける傷が増える）と「脆化」がまぎらわしいので、状態名を「ひび割れ」（英 Cracked）に変えた。氷・錆・石化でひびを入れ、土で叩き割る。おすすめ案として先に入れ、ユーザーの選択待ち。

## 追記（2026-11-23）：呪いを「命を削る」に、今までの効果は「弱り」に
ユーザー「命を削る効果にして、呪いって名前は残して。闇の元素にこだわらなくてもいいけど、虹に呪いはおかしいね」。

- **呪い**（新）：毎秒、最大体力の (curse−1)×5% を削る、4 秒。主・王は 0.3 倍。例：呪い 2.5%/秒、死神 3%/秒。
  - 持つ元素（16種）：墓・呪い・吸血鬼・怨霊・真祖・死神・冥府・百鬼夜行・奈落・地獄門・永劫・無間地獄・古戦場・九尾・呪歌・夢魔。名前や説明に「呪う・命を吸う」が合うもの（系統は問わない）。
  - ITEMS の定義の curse 値はそのまま、読み込み時に drain に変換（DRAIN_K / DRAIN_BOSS / DRAIN_T）。
- **弱り**：今までの「受ける傷が×1.2〜1.6倍」。闇・影・虹・聖光・霧・泥・鈴・風化・金縛りなど23種に残す。説明の「もろくする」は「弱らせる」に統一（英語の brittle / fragile も weaken に）。
- 見た目：呪いは今までの紫の輪と頭上の印、弱りは頭上の橙の山形。詳細画面は「呪い：毎秒、最大体力の 2.5% を削る、4 秒（主・王は 0.8%）」「弱り：受ける傷が 1.2 倍、4 秒」。
- 自動プレイ（ステージ3・11・13、闇＋水／闇＋火＋風）：変更前とほぼ同じか、わずかに楽。
