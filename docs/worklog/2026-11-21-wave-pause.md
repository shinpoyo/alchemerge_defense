# 2026-11-21 波の最中に一時停止できるようにする

## 依頼
「ウェーブ中の一時停止が出来るといい」「一時停止中は購入などは出来ない、止まるだけ」（shinji）

## もともとあった停止の仕組み
- 設定・図鑑・元素の詳細などの重ね合わせの画面を開いている間は、メインループ（`frame()` の `PAUSE_OV`）が戦闘の更新を止めていた。
- 「蓄電は波の最中だけ溜まる」（2026-11-19）は、波と波の間に蓄電が溜まらないようにしたもので、一時停止とは別の話。今回は触れていない。

## 変更（`index.html`）
- 波の最中は、下の波ボタン（「⏸ 迎撃中…」）を押すと一時停止する。波の前は今までどおり波を呼ぶ。
- 一時停止の画面 `#pause` を追加。盤面が透けて見える薄い暗幕に「一時停止」と「▶ 再開」。
  - 重ね合わせの画面なので、開いている間は盤面・作業台・一覧に触れない（購入・合成・売却はできない）。止まるだけ。
  - 画面のどこを押しても再開。
  - `PAUSE_OV` に `pause` を加え、既存の仕組みで戦闘・経過時間の集計を止める。
- キーボード：波の最中に Space または P で一時停止、もう一度で再開。（既存の Space の行は変えず、別のリスナーを足した）
- 下のボタンの並び・幅は変えていない（PR #21 の「戻す」ボタン追加とぶつからないように）。

## 確認（Playwright）
- 波の最中に波ボタンを押す → 一時停止。1.5 秒待っても敵の位置・ゲーム内時間が進まない。
- 一時停止中に一覧の「火」を押す → 魔力が減らない（買えない）。そのまま再開する。
- Space で停止、P で再開。波の番号は増えない。
- ページのエラーなし。
