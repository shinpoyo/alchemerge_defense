# 2026-11-22 下部ボタンを押しやすく整理する（1回目）

## 依頼
スマホ縦画面で、下のボタンが多くて小さく押しにくい。スッキリさせて直感的にしたい。
design-critique スキルでレビューし、案A（ボタンを減らして大きく）をもとに、ユーザーの意見（倍速を右上へ、還すをごみ箱の絵に）を入れて決めた。

## 変えたこと
- 下のボタンを6個から4個にした：第N波・戻す・還す・図鑑と設定（☰）。
  - 図鑑は設定画面のいちばん上に「図鑑 n/200」ボタンとして移した。
  - 倍速は右上（魔力の右）の丸ボタンにした。魔力と工房レベルの表示はその分だけ左へ寄せた。
- 戻す・還す・☰ は、上に絵・下に名前の同じ形にそろえた。還すはごみ箱の絵で、元素をつかんで重ねている間は「ここで還す」と赤く出る。
- ★タブを「★1〜★6」の数字表記にし、高さを 26 → 34（縦長の画面では最大48）にした。まだ元素のないタブの字を少し明るくした（コントラスト 2.9:1 → 約5:1）。
- 下のボタンの高さを 44 → 52（縦長では最大72）にした。そのぶん作業台のマスを 66 → 62 に少し詰めた。

## 確かめたこと
- 412×732（アドレスバーありのスマホ）と 412×860 で画面を撮り、はみ出しや重なりがないこと。
- 倍速の丸ボタンで ×1 → ×2 に変わること、☰から設定が開き図鑑ボタンがあること。
- 作業台の元素をごみ箱へ運ぶと「ここで還す」と出て、還せること。英語表示でも文字が収まること。

## 次
フィルターと並べ替え（全・★1〜★6・⇅、窓は波の最中なら一時停止）は2回目のPRで入れる。
