# 2026-11-22 風の系統を増やす

## 依頼
「風ってなんでそんなに少ないの？」→ 風を混ぜた元素の多くが相手側の系統になっていたため、風は8種だけだった（他は11〜29種）。提案に「はい、そうしてください」。

## 変更
名前に風らしさがある4種を「元の系統＋風」の2系統にした（index.html の MULTI）。

| 元素 | 前 | 後 |
|---|---|---|
| 砂嵐 | 土 | 土＋風 |
| 熱風 | 炎 | 炎＋風 |
| 雷鳥 | 雷 | 雷＋風 |
| 神嵐（海神＋風神） | 雷 | 雷＋風 |

風の系統の元素は 8 → 12 種（結界を除く）。水＋雷／氷＋土の組ではないので自己シナジーは起きない。

## 確かめたこと
- ページを開いてエラーなし、4種の fam が2系統になっていることを確認。
- 瘴気の沼（風が弱点）を火・風だけで自動プレイ（simBases.js）：変更前後でほぼ同じ結果で、難易度は崩れていない。
