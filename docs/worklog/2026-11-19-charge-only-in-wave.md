# 2026-11-19 蓄電は波の最中だけ溜まるようにする

## 依頼
「蓄電は波が止まっているときには溜まらないようにしてほしい」

## 解釈
「波が止まっている」＝ 波を呼ぶ前・波と波の間（`S.active` が false）の状態。
メニューなどを開いている一時停止中は、もともと戦闘の更新自体が止まっているので対象外（変化なし）。

## 変更
- `index.html` の `idleChg()`：`S.active` が false のときはチャージを増やさずに戻る。
  - 溜まりかけの時間（`chgT`）はリセットせず止めるだけ。次の波で続きから溜まる。
  - すでに溜まっているチャージは消さない（前の波で溜めた分は次の波に持ち越す）。
- 説明文（「敵がいない間に蓄え」）は変更していない。

## 確認
Playwright で電磁砲を置き、×1／×2／×3 それぞれで確認。
- 波の間に 3 秒待つ → チャージ 0（3 速とも）
- 波の最中に敵がいない状態で 2.5 秒 → ×1 で 1、×2 で 3、×3 で 4〜5（速度に比例して溜まる）
- 波が終わったあともチャージは残り、増えない
- ページのエラーなし
