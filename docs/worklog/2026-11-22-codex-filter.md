# 図鑑にしぼりこみと並べ替えを付ける（2026-11-22）

## 依頼
- 「図鑑にもフィルター、ソート機能つけて」
- 「フィルターは系統でもかけれるようにして」

## やったこと
- 図鑑の見出しの下に「⇅ しぼりこみ・並べ替え」ボタンを追加。押すと、ゲーム画面の⇅と同じ窓が図鑑の上に開く（後ろの図鑑で結果がその場で見える）。
- 条件はゲーム画面の⇅と同じ（★・置き場所・はたらき・並べ替え）に、新しく **系統**（炎/水/土/風/雷/氷/毒/闇/光/音/系統なし）を追加。2系統の元素はどちらの系統でも当てはまる。鋼・竜・要石などは「系統なし」。
- 系統の行はゲーム画面の⇅にも入れた（条件をそろえるため）。
- 図鑑の窓の違い：
  - 並べ替えは ★順・安い順・威力順（「最近作った順」はその戦いの記録なので図鑑には出さない）。
  - スイッチは「見つけたものだけ出す」。
  - ★以外でしぼっている間は、まだ見つけていない元素は出さない（ゲーム画面の一覧と同じ決まり。未発見の中身が分かってしまうため）。
  - ★順のときは★ごとの見出しつき、ほかの並べ替えでは見出しなしで並べる。
  - 図鑑の条件はゲーム画面の条件とは別に覚える。しぼり中はボタンが金色＋点。
- 詳細画面の「前へ・次へ」は、しぼりこみ・並べ替えのあとの図鑑の並びで送るようにした。

## 確認
- Playwright（390×844）で、炎でしぼって威力順 → 並びが威力の高い順、詳細の次へがその順で進むことを確認。コンソールエラーなし。
