# 図鑑の購入ボタンをなくす（2026-11-21）

## 依頼
PR #21 で図鑑のカードに付けた購入ボタンのせいで、スマホでカードの高さがばらばらになり図鑑がガタガタに見える。図鑑の購入ボタンはなくす。

## 変えたこと（index.html）
- 図鑑のカードから「◆値段 購入」ボタンを外した。あわせて、購入のために足した図鑑上部の魔力表示（文言 `cMana`）と、そのクリック処理も外した。
- 元素の詳細画面の購入ボタンは残す（図鑑のカードをタップ → 詳細から購入できる）。

## 確認
- Playwright で図鑑にボタンが出ないこと、詳細画面からは購入できることを確認。エラーなし。
