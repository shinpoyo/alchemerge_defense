# 2026-11-26 ★ごとの強さをなだらかにする

## きっかけ
- shinji さんの問い「★低くてもたくさん置くか、強いのを一つ置くか」。自動プレイで比べると、同じ魔力でも★高が圧倒的で、★1〜3を12マス埋めても★4数個に負けた。
- 「★高い方が強いのは当たり前だけど少しなだらかにしたい」「雑魚が普通にプレイして真ん中くらいまで来る感じにしたい。今は出口近くに海神を置くと姿も見えない」。
- 3案（下を上げる／上を下げる／両方を少しずつ）から「両方を少しずつ」を選択。

## 調べたこと
- 全元素の魔力あたりの威力（中央値）: ★1 0.60 / ★2 0.70 / ★3 0.77 / ★4 1.38 / ★5 1.69 / ★6 4.29。★3と★4の間に段差があった。
