# 2026-11-23 ゲームのファイルを分割する

## 経緯
コードレビューのあと、ユーザーから「ファイルがひとつなのはいいのか？」と聞かれた。PRどうしのぶつかりやすさや差分の読みにくさを説明し、分割を提案した。ユーザーの指示「ファイルを分割してください」で実施。

## やり方
- 約4,150行の index.html を、HTML・CSS・JavaScript 17ファイルに分けた。
- コードの中身は変えていない。行をそのまま切り分け、各ファイルの先頭に `'use strict';` と一行の説明を足しただけ。
- ビルドなしのまま、ふつうの `<script src>` を上から順に読みこむ（`type="module"` は使わない）。こうすると、これまでどおり index.html をダブルクリックしても動く。また、`const` や `let` もファイルをまたいで共有される。
- 注意：あとのファイルは前のファイルで決めたものを使うので、読みこむ順は変えられない。読みこんだ時点で動く行が、まだ読みこんでいないファイルの関数を呼ぶとエラーになる。
