# 2026-11-23 乾きは水に、炎には「火種」

## 依頼
- 「水に弱いものは？」→ 現実では乾いた土や砂は水で崩れる、と答えた。
- ユーザー「乾きで水に弱くなるは、いいけど、火は別を考えよう。例えば燃えるものをつけるとかでもいいだろうし」

## 変更
| 状態 | かける元素 | よく効く系統 |
|---|---|---|
| 乾き | 旋風・竜巻・砂嵐・風神・干ばつ・荒野 | 炎 → **水** に変更 |
| 火種（新） | 木の葉・木の精・胞子・沼・毒沼 | 炎 |

- 乾き：乾いた土や砂が水で崩れるイメージ。乾ききった地の 干ばつ・荒野 も足した。
- 火種：燃えるもの（木の葉、木の精、胞子、沼のガス）をまとわせ、炎がよく燃える。
- どちらも ×1.5・2.5 秒（主・王は半分）。かける元素によく効く系統を持つものはない（スクリプトで確認）。
