# 2026-11-22 沈黙は永続効果だったかの確認（PR #30 / #31）

## 依頼
「PR #30 にコンフリクトがあり内容が気になる。沈黙はあえて永続効果にしていたと思うがどうか」の確認。コードの変更はしていない。

## わかったこと
- PR #30（属性シナジー：濡れ・脆化）は 2026-11-22 03:57 UTC にマージ済み。沈黙には触れていない（沈黙・鎧の軽減とは独立）。
- 沈黙を直すのは PR #31「呪い・沈黙のタイマーが減らない不具合を修正」（未マージ）。コンフリクトがあるのはこちら。
  - 原因：#30 が同じ箇所の次の行に `wetT`/`britT` の減少処理を足したため。中身はぶつかっておらず、両方残せば解消できる。
- 沈黙は当初から **時間制** の設計：
  - 8c0782e（2026-11-17「新効果3種（沈黙・蓄電・跳弾）を実装」）で `if(e.silT>0)e.silT-=dt;` を追加。
  - 詳細文は「敵の力を {0} 秒封じる」。瘴気・霧 2 秒、闇夜 2.5 秒、賢者の石 3 秒。
  - 結界（浄めの霧・聖域）だけは「広さの中にいる間ずっと沈黙」。毎フレーム `silT=0.3` を入れ直す作りで、出れば解ける前提。
- 永続になったのは不具合：d07c464（2026-11-17「停止中は減速タイマーを進めないよう調整」）で、行の途中に `//` コメントを入れたため、
  同じ行の後ろの呪い（curseT）と沈黙（silT）の減少処理がコメント扱いになった。→ 呪い・沈黙ともに倒れるまで解けない状態。

## 未決
