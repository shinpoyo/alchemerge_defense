# 2026-11-19 ★ランクと名前の格のズレを直す

## きっかけ
「★ランクが同じなのに名前の強さが全然違うものがある（雷雨と雷神など）」という指摘。

## 調査で分かったこと
- 雷雨・雷神はどちらも★4。性能は雷神のほうが上だった。
- ★の数はレシピ（同じ★どうしを重ねると★+1）と結びついているので、★を動かさず名前で直す。
