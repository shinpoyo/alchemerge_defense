# 2026-11-23 悪霊・悪魔・魔王を「呪い」に

## 依頼
「悪霊、悪魔、魔王は呪い入れて、リリスは誘惑だから」

## 変更
- 悪霊・悪魔・魔王を、弱り（受ける傷が増える）から呪い（命を削る）に変えた。読み込み時に curse→drain に変換する一覧に追加。
  - 悪霊 1.75%／秒、悪魔 2.25%／秒、魔王 2.5%／秒（主・王は 0.3 倍）。
- 説明を「弱らせる」→「呪う」に（英語 weakening → cursing）。
- リリスは誘惑の元素なので弱りのまま。

## 確かめたこと
- コンソールエラーなし。3種に drain が付き、curse が外れていることを確認。

## 追記：「弱り」を「弱体」に
ユーザー「弱りって言うのがダサいからやめたい」。状態名を「弱体」（英 Weakened）に変えた（おすすめ案として先に入れ、選択待ち）。

## 追記：受ける傷が増える効果（弱体）をなくす
ユーザー「まず、ダメージを受けやすくなるのは無しにする」。

- しくみ（e.curse・curseT、状態「弱体」、詳細の行、頭上の印）を削除。持っていた29種から外した。
- ほかに効果がなくなる10種は、今ある効果を付け替えた。
  - 闇・影 → 怯え（光が効く）をかける
  - 風化・侵食・遺跡 → ひび割れ（土が効く）をかける（風化はもともと）
  - 聖光 → もともと眩みをかける
  - 鈴・鎮魂歌・葬送曲・抜け殻 → 減速（20%・30%・40%・30%、1秒）
- ほかの19種は説明から「弱らせる」を外すだけ（遅くする・止める・惑わす等はそのまま）。
- 万華鏡の闇の弾（curse 1.45）は呪い（2.25%/秒）に。
- 自動プレイ（ステージ3・11・13、闇＋水／全基本元素）：main とほぼ同じ結果。
