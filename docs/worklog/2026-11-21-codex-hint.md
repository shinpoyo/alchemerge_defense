# 図鑑の未発見ヒントを復活させる（2026-11-21）

## きっかけ
図鑑 193/200 で、★4 をほぼ集めているのに ★5 の「？」がすべて「？ ＋ ？」のままだった。

## 調べたこと
- 全200種は基本元素から作れる。材料が存在しない・登録漏れ・★のずれ（崩れて★が下がる特別なものを除く）はなかった。
- PR #20 で、未発見カードのヒント（材料の片方を見せる）の条件が「材料が両方とも図鑑にある」から「その組み合わせで錬成したことがある」に変わっていた。
  錬成すればその時点で元素は発見済みになるので、この条件では未発見カードにヒントが出る場面がなくなっていた。

## 変更
- `openCodex` の未発見カードのヒントだけ、元の条件（材料が両方とも `disc` にあれば片方を見せる）に戻した。
- 発見済みカード・詳細画面の作り方表示は PR #20 のまま（実際に作った組み合わせだけ）。

## 確かめたこと
- Playwright で全元素を発見済みにし、★5 の4種と天地鳴動を外して図鑑を開いた。★5 の4種は「材料 ＋ ？」、材料の片方が未発見の天地鳴動は「？ ＋ ？」になった。ページのエラーなし。
