# 2026-11-22 一覧のしぼりこみと並べ替え（下部ボタン整理の2回目）

## 依頼
下部の★タブはフィルターの役割なので、★以外の条件と並べ替えもほしい（ユーザー）。図で合意した形で作った。

## 変えたこと
- ★の行を「全・★1〜★6・⇅」にした。「全」は全部の★を1列に並べ、札の左上に★を小さく出す。
- ⇅を押すと、★の行のすぐ上に窓が開く。
  - 置き場所：すべて／塔／罠
  - はたらき：すべて／燃やす・毒／遅くする／巻きこむ／連鎖／貫通／強くする（どれか1つ）
  - 並べ替え：★順／安い順／威力順／最近作った順
  - 「呼べるものだけ出す」スイッチ
  - 最下段に「リセット」（文字リンク）と「とじる」。条件のチップとは場所と見た目を分けた（ユーザー指摘）。
- 窓を開いている間はゲームを止める（ほかの画面と同じ仕組み）。波の最中は「⏸ 一時停止中」と出す。
- しぼりこみ・並べ替えをしている間は、⇅が金色になり点が付く。
- しぼっている間は、まだ見つけていない札は出さない（はたらきが分かってしまうため）。

## はたらきの判定
- 燃やす・毒：dot がある（燃焼と毒は同じしくみのため、ひとまとめにした）
- 遅くする：slow / stop / stun がある
- 巻きこむ：splash がある、または kind が pulse
- 連鎖：kind が chain、貫通：kind が pierce、強くする：kind が support
- 威力：dmg × rate × beams + dot

## 確かめたこと
- 412×732 で、窓の開閉・選択・リセット・とじるを操作し、画面を撮った。
- 波の最中に窓を開くと、ゲームの時間が進まないこと。
- コンソールにエラーが出ないこと。

## 追加の直し（ユーザーの意見）
- 窓の中にも★（ランク）の項目を足した。
- ★・置き場所・はたらきは、どれもいくつでも選べるようにした。何も選んでいなければ全部を出すので「すべて」はなくした（1つだけ見たいとき、1回押すだけで済むため。おすすめとして提案）。
- 通常画面の「全」ボタンはなくし、★1〜★6と⇅だけにした。★タブは窓の★の近道で、押すとその★だけを選ぶ。光っているタブをもう一度押すと全部に戻る。窓で★1と★2を選ぶと、両方のタブが光る。
- 最初の状態は★を選んでいない（全部を出す）。★が2つ以上か何も選んでいないときは、札の左上に★を小さく出す。
