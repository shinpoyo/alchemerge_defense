# 2026-11-20 設定に振動のオン/オフを追加

## 依頼
設定から振動をオンオフできるようにする。

## 変更
- 設定メニューの「ダメージ数字」の下に「振動：オン / オフ」ボタンを追加（英語表示は Vibration: On / Off）
- `vibOff` をセーブに保存し、次回起動時も維持。進捗の初期化でも音・言語・ダメージ数字と同じく残す
- オフのときは `buzz()` が `navigator.vibrate` を呼ばない
- オンに戻したときは確認のため一度だけ短くふるわせる

## 確認
- Playwright で切りかえ → 保存値 `vibOff:true` → オフ中は振動が呼ばれない → 再読みこみ後もオフのまま → 英語表示、を確認。コンソールエラーなし
