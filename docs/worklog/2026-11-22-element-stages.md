# 2026-11-22 属性特化ステージ（凍てつく湖・沈んだ都）

## 依頼
- 系統の結界（PR #32）に続き、属性に特化したステージを入れる（設計書 https://claude.ai/artifact/LGqcTcBzFTqoyrdW6R2kSS の「属性の地」）。ユーザーが「進めて」。

## やったこと
- STAGES に aff を足せるようにした。影が受ける傷：aff.weak の系統 ×1.5（AFF_WEAK）、aff.resist の系統 ×0.5（AFF_RES）。2系統の元素は両方掛かる。
  - 鎧の影は、属性の地では resist の系統をいつも防ぐ（armorFam）。
  - aff.wet：影がいつも濡れている（雷に PR #30 のシナジー ×1.5）。
- 新ステージ2つ（最果ての祭壇のあと。前をクリアすると開く）
  - 凍てつく湖：凍った湖のまわりを一周して中央の灯へ。弱い：炎、効きにくい：氷。hp 1.25、spice 1.1。
  - 沈んだ都：左上と右の水路が合わさって下の灯へ。いつも濡れていて雷が効く、効きにくい：水。hp 1、spice 1.1。
- 表示：ステージ一覧に「弱い：炎　効きにくい：氷」、第1波のはじめに同じ一文。湖の影には水色の点線の輪、都の影は濡れの印。背景は湖が青い星雲と氷のひび、都が波紋。
- 魔法陣の並びは灯に近い順（自動プレイが近いマスから置くため）。

## 確かめたこと（balance-sim/sim.js をもとに、使う基本元素を指定できるようにした版）
- 凍てつく湖 hp 1.25：水だけ→20波クリア（灯-10）、火だけ→第19波で陥落。砂時計の峠では火だけ第6波陥落なので、炎が通りやすくなっている。
- 沈んだ都 hp 1：火だけ→第15波、火＋風（雷）→第10波、水だけ（効きにくい）→第8波で陥落。砂時計の峠（火＋風で第11波）と同じくらい。
- コンソールエラーなし。

## 追記：要石の見直し（ユーザー指摘）
- 要石は無系統にした（土・光をやめた）。
- 説明文を「どの系統の★4と錬成しても、その系統の結界になる。自らも重い石を落とす」に。
- 詳細の「これを使う錬成」は、要石＋炎の系統の★4＝炎の結界、のように系統ごとに9行で出す（37個を並べない）。結界の「作り方」も同じ1行で出す。
- 系統の★4の詳細「これを使う錬成」には要石の錬成を出さない（要石の側にだけ出す。ユーザー指示）。
- 結界の作り方を「その系統の★4ならどれでも」から、1つずつ決めた形に変更（ユーザーと相談）。要石＋煉獄＝炎、津波＝水、霊峰＝土、嵐＝風、万雷＝雷、永久凍土＝氷、腐海＝毒、怨霊＝闇、天光＝光。結界のレシピは37本→9本。普通の錬成として表示するので、系統表記や★4側で隠す特別扱いはなくした。
- 要石の説明文は元の「地を鎮める重い石を落とす」に戻した（ユーザー指示）。
