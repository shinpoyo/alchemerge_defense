# 2026-11-28 罠が塔より弱いかを数字で確かめる（調査のみ・実装なし）

- 依頼: 「罠が効きにくい敵はいるけど、効きやすい敵はいない？罠弱い説」→ 罠を強化する方針、方法は未定。まず数字で確かめる。
- やったこと: 自動プレイで、同じ魔力の「★4の塔N本」と「塔N−1本＋★4の罠1つ」を15面×王の波／7割の波で比較。罠・塔を1つだけ置いて敵の種類ごとの効き方も測った。
- 結果（罠1つ＝塔何本ぶん）: 永久凍土・蟻地獄は約1本、底なし沼0.3〜0.6、石化0.4〜0.8、煉獄・腐海・陽炎・妖精の輪は0.1前後。
- 敵ごと: 遅くする罠に得意な相手はいない。止める罠は主・王にほぼ効かない。焼く罠は重い敵・主に塔の半分以下。蟻地獄だけは足の遅い敵を押し戻しで完全に止める。
- 強化の方向（案）: 重い敵に罠がよく効く／罠の遅さを塔の遅さと重ねる／止める罠を王にも少し／数値の底上げ。ユーザーが決めてから実装する。
- 詳細とスクリプト: 共有フォルダ trap-strength/（2026-11-28-trap-strength.md、trapMix.js、byType.js ほか）。

## 2026-11-29 名前に合わない塔の効き目を外す

- ユーザー決定: 罠の役割をはっきりさせるため、名前から効き目が出そうにない塔の効き目を外す（懐中時計の「止める」は残す）。燃やすもおかしいものは外す。
- 外した効き目（20種）: 遅く＝虹・オーロラ・黄昏・抜け殻・鈴・闇夜・葬送曲・楽園・賢者の石・竜・永劫・創世／止める＝化石／毒＝密林・樹海・死神・世界樹／呪い＝永劫／燃やす＝楽園・吸血鬼・真祖・怨霊。効き目を書いていた説明文は日本語・英語とも直した。
- 威力の埋め合わせ: ユーザーが「大きく落ちたものだけ埋める」を選択。塔1つで体力のある影30体に与える傷（trap-strength/towerReal.js、3面平均）が3割以上落ちた7つの威力を上げた。竜は威力を上げず、遅くするの代わりに燃やす（dot 100、★5の聖剣とほぼ同じ強さ。1080 はユーザーが高すぎると判断）、楽園 150→290、樹海 35→70、世界樹 110→175、葬送曲 30→50、密林 20→30、闇夜 14→21。埋めたあとは元の −5〜+5%。竜は元の遅さで敵が固まり貫通が多く当たっていたぶん高く出ていたので、元には合わせず聖剣（1695）と同じくらい（1693）にした。
- 埋めなかったもの: 虹・オーロラ・黄昏・鈴（−19〜−28%、★2）、賢者の石・創世（−3〜−5%）、化石・抜け殻（変化なし）、吸血鬼・真祖・怨霊・死神・永劫（呪いが主で、焼く・毒は直接の攻撃の3〜4割ぶん）。
- 次の検討: 名前が罠に合う塔（池・茂み・温泉・荒野・古戦場・砂漠・樹海など）を罠にするかはユーザーが選ぶ。
