# 2026-11-22 系統の結界と属性ステージの設計

## 依頼
- 系統の種類を知りたい
- 範囲内の特定系統のダメージを強める「結界の塔」（例：火の結界で火×2）を作りたい
- 属性に特化したステージ（例：氷の敵が多く火が効く）も考えたい

## 調べたこと
- 系統は FAMOF（元素→系統）で決まり、ITEMS の fam に入る。12系統＋無属性（灰）。
  - 光32・音31・炎24・土24・闇18・水16・雷13・氷13・毒13・鋼8・風7・竜2・無1
- 使い道：発射音（FAM）、鎧の影が防ぐ9系統（ELEM）、PR #30 の属性シナジー（濡れ→雷×1.5、脆化→土×1.5、hurt() 内）
- 既存の結界（浄めの霧・聖域）は wardTick で範囲内の影に状態をかける仕組み。支援の塔は塔側を強め、最も強い1つだけ効く。

## 設計案（未実装・ユーザーの承認待ち）
- 設計書: https://claude.ai/artifact/LGqcTcBzFTqoyrdW6R2kSS
- 結界：影の側にかかる。範囲170の中の影が、その系統から受ける傷×2（仮）。9系統、★5。
  - 要石★4（山＋聖光）＋その系統の★4 → ○の結界。レシピ37本＋1本。
  - シナジー・呪い・鎧とは掛け算（雷の結界×濡れ＝×3）。強すぎれば大きいほうだけにする。
- 属性の地：ステージに「弱い系統×1.5／効きにくい系統×0.5」。凍てつく湖（氷）・沈んだ都（水、影がいつも濡れ）など。
- バランスは balance-sim で「12マス塔」と「11マス＋結界」を比べてから倍率を決める。
