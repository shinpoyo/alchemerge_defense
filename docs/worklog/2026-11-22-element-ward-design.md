# 2026-11-22 系統の結界と、系統の見直し

## 依頼
- 系統の種類を知りたい
- 範囲内の特定系統のダメージを強める「結界の塔」（例：火の結界で火×2）を作りたい
- 属性に特化したステージ（例：氷の敵が多く火が効く）も考えたい
- （追加）複数の系統を持つ元素を作る（混沌＝炎と氷、風神雷神＝雷と風）。竜・鋼の系統はなくして無系統にする

## 調べたこと
- 系統は FAMOF（元素→系統）で決まり、ITEMS の fam に入る。変更前は12系統＋無属性（灰）。
  - 光32・音31・炎24・土24・闇18・水16・雷13・氷13・毒13・鋼8・風7・竜2・無1
- 使い道：発射音（FAM）、鎧の影が防ぐ9系統（ELEM）、PR #30 の属性シナジー（hurt() 内）
- 既存の結界（浄めの霧・聖域）は wardTick で範囲内の影に状態をかける。支援の塔は塔側を強め、最も強い1つだけ効く。
- 設計書: https://claude.ai/artifact/LGqcTcBzFTqoyrdW6R2kSS （ユーザーが「おすすめ案で実装」を選択）

## やったこと
- 系統を配列にした（ITEMS[k].fam は配列。灰・鋼・竜の元素は空＝無系統）。
  - 鋼・竜の系統をなくした。発射音だけは元の音色（TONE）を残す。鎧の影が防ぐ9系統は変わらない。
  - 2つの系統を持つ元素（MULTI）：黒炎・鬼火（炎＋闇）、プラズマ（雷＋炎）、蒼炎・混沌（炎＋氷）、温泉（水＋炎）、天災（雷＋氷）、台風・嵐（風＋水）、太陽（炎＋光）、要石（土＋光）、光子砲（光＋雷）、地獄門（炎＋毒）、風神雷神（雷＋風）、永劫（闇＋雷）、無間地獄（闇＋氷）
  - 鎧・結界・属性シナジーは、どれか1つの系統が当てはまれば働く。水＋雷、氷＋土の組み合わせは自分でシナジーを起こすので作らなかった。
  - 詳細画面は「炎・氷の系統」と並べ、シナジーの一文も系統ごとに出す。
- 系統の結界（9種、★5、範囲170、×2）：炎・水・土・風・雷・氷・毒・闇・光の結界。
  - 影の側にかかる（wardTick で輪を集めて S.amps、hurt() の ampAt で×AMP_MUL）。同じ系統は重ならない。シナジー・呪いとは掛け算。
  - 新素材「要石」★4（山＋聖光、土＋光、弱い弾）。要石＋その系統の★4ならどれでも結界になる（レシピ37本＋1本）。
  - 絵は点線の輪の中にその系統の元素の絵。要石は注連縄を巻いた石。
- 元素 200→210種、レシピ 229→267本。

## 追記：濡れ・脆化を「敵にかける効果」に出す（ユーザー指摘）
- 水・氷の系統の攻撃する元素は、詳細の「敵にかける効果」に「濡れ　雷の攻撃を ×1.5 で受ける、2.5 秒」「脆化　土の攻撃を ×1.5 で受ける、2.5 秒」を出す（SYN_MUL・SYN_T から）。
- 上の説明欄の「水は濡れ→雷が効く」「氷は脆化→土が効く」はそちらへ移したので消した。雷・土の側の一文（濡れた敵に ×1.5）は残す。
