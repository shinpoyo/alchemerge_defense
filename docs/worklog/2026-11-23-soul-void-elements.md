## 追加したもの

- 新しい元素 **38 種**（魂 20・無 14・時と夢の組み直しで 4）、メトロノームを削除。253 → **290 種**、282 → **322 本**
- **魂**（20 種）：砂時計の峠（ステージ 6）のクリアで届く（`UNLOCK` に `soul:6`）
  - ★1 魂／★2 人魂・霊魂・幽霊・木の精・守護霊／★3 悪霊・妖精・天使・神霊・ゾンビ／★4 大天使・妖精の輪・悪魔・サキュバス／★5 セラフィム・魔王・堕天使・リリス／★6 ルシファー
- **無**（14 種）：最果ての祭壇（ステージ 7）のクリアで届く（`UNLOCK` に `void:7`）
  - ★1 無／★2 真空・静寂・干ばつ・穴・抜け殻・空虚／★3 真空刃・洞窟・荒野・ミイラ・虚無／★4 虚空／★5 ブラックホール
- **新しい系統「魂」「無」**（`FAMS` / `FAMOF` / 音色 / `f_soul` `f_void`）。鎧の影が防ぐ系統（`ELEM`）と結界には入れていない（時・夢と同じ）
- **新しい仕組み**
  - **魂集め**（`soul`・`soulMax`）：その塔が敵を倒すたびに威力が `soul` ずつ上がる（上限 `soulMax`、その戦いの間だけ）。魂・霊魂・神霊が持つ。倒した敵から塔へ魂が飛ぶ
    - どの塔が倒したかは `HIT`（いま当てている塔）で見る。弾・跳弾・こだまは撃った塔を持ち運ぶ。毒・燃焼・罠・結界で倒したときは数えない
  - **誘惑**（`lure`・`lureP`）：当たった敵が、その塔にいちばん近い道まで引き返して（または進んで）立ち止まる。解けたあと `LURE_RES`=4 秒は効かない、主・王には効かない。頭の上にハートが出る。サキュバス・リリスが持つ
  - **消し去る**（`erase`）：体力が最大の `erase` 割以下の敵を消す（主・王には効かない）。無・空虚・虚無・虚空・ブラックホールが持つ
- しぼりこみの「足止め」に誘惑も入るようにした（`ROLE.slow`）。詳細画面の「敵にかける効果」に誘惑・消し去る・魂集めの行を追加
- アイコン 38 個・英語名と説明・攻撃の見た目（`VIS`）。ゾンビの継続ダメージは「毒」

## 系統図から変えたところ

- 無の仕組みは系統図では「守りを無視して当たる」だったが、無の系統は鎧の影が防ぐ 9 系統にも、ステージの「効きにくい系統」にも入らないので、もともと守られない。意味のある違いが出ないため、**体力の少ない敵を消し去る**（無に帰す）にした。説明文もそれに合わせた
