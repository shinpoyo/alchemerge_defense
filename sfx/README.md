# 外部効果音（`sfx/*.mp3`）

このフォルダに配置された `.mp3` ファイルは [`js/audio.js`](../js/audio.js) により自動で読み込まれ、Web Audio 合成の代わりに再生されます。
**ファイルが存在しない（または読み込み失敗した）項目だけ、自動的に従来の Web Audio 合成へフォールバック**します。

## 差し替え方法
気に入ったフリー素材や自作音源があれば、同じファイル名で上書きするだけで反映されます（モノラル・ステレオどちらも可、44.1kHz MP3 推奨）。

| `pick.mp3` | 元素をつかむ |
| `drop.mp3` | 元素を置く |
| `spawn.mp3` | 一覧から元素を召喚 |
| `fail.mp3` | 錬成失敗・魔力不足 |
| `merge_1.mp3` | 錬成成功（★1〜2） |
| `merge_2.mp3` | 錬成成功（★3） |
| `merge_3.mp3` | 錬成成功（★4以上） |
| `disc.mp3` | 新元素の発見 |
| `moon_open.mp3` | 月の恵みの出現 |
| `moon_pick.mp3` | 月の恵みの札選択 |
| `kill.mp3` | 通常の影の撃破（連続撃破時は音階ピッチ変化） |
| `thud.mp3` | 大型の影の撃破 |
| `boom.mp3` | 夜の主・夜の王の撃破 |
| `warn.mp3` | 夜の主 接近警告 |
| `king_intro.mp3` | 夜の王 降臨カットイン（4.65秒：0〜1.35s DANGER → 1.35〜2.15s 影 → 2.15s 顕現） |
| `wave.mp3` | 通常波の開始 |
| `wave_boss.mp3` | 主・王の波の開始 |
| `wave_end.mp3` | 波のクリア |
| `clear.mp3` | ステージクリア |
| `over.mp3` | 砦陥落（ゲームオーバー） |
| `ach.mp3` | 実績解除 |
| `leak.mp3` | 敵が灯に到達・ダメージ |

## 再生成
`scripts/gen_sfx.py` でオフライン合成（モーダル鐘・多層ブラス・太鼓・ステレオ残響・マスタリング）を再実行できます：
```bash
python3 scripts/gen_sfx.py
```
